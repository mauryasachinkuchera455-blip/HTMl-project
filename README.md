# Student Identity Card (ID) Replacement and Reissue System

**Team:** Group 17 — Coder Group  
**Members:** Sachin, Sahid, Shubham  
**Course:** Academic Tasks (26271)

## Project overview
A responsive front-end prototype for students who need a replacement/reissued university identity card. Students can submit an application, select a reason, tick a document checklist and track the application. A demonstration admin area can change the request status.

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Fill out the replacement application form and submit it.
4. Copy the generated application ID (format `IDR-######`).
5. Use the Track Request section to view the current status.
6. In the Admin section, change Pending to Approved or Rejected, then track again.

No installation or build command is required.

## Technologies
- HTML5 — page structure and forms
- CSS3 — responsive layout and visual design
- JavaScript — form validation, application ID generation, tracking and status updates
- Browser localStorage — saves demo applications on the same browser/device

## Main modules
1. Student information form
2. Replacement reason selection (Lost, Damaged, Stolen, Details correction, Other)
3. Document checklist
4. Application submission and unique application ID
5. Application tracking
6. Admin demonstration dashboard and status management

## Important limitations
This is a classroom front-end prototype. Data is stored only in the browser's localStorage and is not shared between devices. It does not provide real student authentication, secure file uploads, server/database storage, email/SMS notifications or payment processing. These would be required before real university use.
